
# Project Layout

This is a single-file web app. Keep `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` at the top level so GitHub Pages can serve `index.html`.

- `00_planning/` contains notes and sketches; use `notes/`, `sketches/`, and `feature-ideas/` for planning materials.
- `01_data/` contains data files, such as USGS downloads.
- `02_validation/` contains hand calculations and test cases.
- `03_output/` contains screenshots and exported results.

Save every new file in the folder that matches its purpose. Do not create unrelated top-level folders or files.
